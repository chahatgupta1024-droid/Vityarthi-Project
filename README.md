Project title :
Gaming develpment

OVERVIEW OF PROJECT:
This project is a Python-based implementation of the classic game Rock, Paper, Scissors.
The game is designed to allow a user to play against the computer in a fun and interactive way.
The program randomly selects the computer’s choice and compares it with the user’s input to determine the winner based on standard game rules.
This project helps in understanding basic programming concepts such as conditional statements, loops, user input handling, and the use of random functions.
It also demonstrates how simple logic can be used to build an engaging game

FEATURES:
Interactive and easy-to-use game
Computer makes random choices
Validates user input
Shows clear results (win/lose/draw)
Allows multiple rounds
Simple and fast execution
Clean and readable code
