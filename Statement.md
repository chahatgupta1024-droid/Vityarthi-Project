PROBLEM STATEMENT:
The objective of this project is to create a simple and interactive **Rock–Paper–Scissors game** using Python.  
The system should allow a user to play against the computer, where the computer randomly selects one of the three options: **Rock**, **Paper**, or **Scissors**.
The program must:
- Accept user input.
- Validate the input.
- Generate a computer choice at random.
- Compare both choices based on the game rules.
- Display the result: **Win**, **Lose**, or **Draw**.
- Ensure smooth game flow with clear instructions and outputs.
This project aims to demonstrate basic Python concepts such as conditional statements, loops, user interaction, and random number generation.

SCOPE OF THHE PROJECT:
The scope of this project includes:
- Developing a **Rock–Paper–Scissors game** using Python for console-based interaction.
- Allowing the user to input their choice and validating the input.
- Generating a **random computer choice** using Python's `random` module.
- Implementing the game logic to determine the outcome:
  - User wins  
  - Computer wins  
  - Draw  
- Displaying clear, user-friendly messages for each round.
- Supporting repeated gameplay until the user decides to stop.
- Demonstrating fundamental programming concepts:
  - Conditional statements  
  - Loops  
  - Randomization  
  - Input/output handling
